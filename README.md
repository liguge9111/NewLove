# NewLove

一款运行在 Android 上的 **AI 角色扮演伴侣应用**（酒馆类客户端）。支持 SillyTavern 生态角色卡、多互动模式、手机 IM 式聊天、动态状态栏与语音交互，本地存储、微信风格界面。

> ⚠️ 本应用面向成年用户，内容完全由你导入的角色卡与所配置的大模型生成。所有数据仅保存在本机。

---

## 功能总览

### 角色卡系统
- 支持 TavernAI V1 / SillyTavern V2 / V3 角色卡，PNG 与 JSON 双格式导入
- 完整解析：设定、性格、场景、世界书（character_book）、多开局（alternate_greetings）、创建者信息
- 详情页四分区浏览：基础设定 / 世界书条目 / 多开局预览 / 状态栏模板编辑
- 开局选择器：默认开局与全部备选开局，选定后作为聊天首条消息

### 大模型接入
- OpenAI 兼容（含 DeepSeek、各类中转网关）、Anthropic Claude、本地 Ollama
- 流式输出（SSE）、温度/采样等参数可调、一键连接测试
- 推理模型适配（reasoning_content 分片过滤、空回复检测与提示）

### 互动模式
| 模式 | 说明 |
|---|---|
| 文字冒险（默认） | AI 主导第二人称叙事，输入行动推进剧情 |
| 视觉小说 | 每轮输出 3～4 个 30–60 字分化选项，选项可携带状态增量，支持直接发送/预览确认 |
| 自由扮演 | 沉浸式角色扮演，保持人设 |

### 手机 IM 聊天（微信式）
- 互动页右下角悬浮球 → 全屏微信风聊天界面（圆角头像、绿白气泡）
- **实时模式**：消息直接进入叙事，角色回复附带 `[IM]` 块回显到聊天界面
- **聊天增强模式**（可开关）：先进行纯 IM 对话生成，每轮结束后自动把「你发了 X、她回了 Y」同步进互动剧情（每条消息消耗两次模型调用）
- 玩家昵称/头像设定，`{{user}}` 变量自动替换

### 动态状态栏
- **数值状态**：按角色卡模板定义（心情/体力/好感或自定义项），AI 通过 `[STATUS]` 增量更新，独立折叠区常驻
- **文字状态栏**：多协议自动识别，置顶面板展示
  - `<Status_block>` / `<maintext>` 标准协议
  - `<style>` + HTML 卡片面板（TavernHelper 等）
  - `<Comment_of_Master>` + `<Master_Talk>` 传念协议
  - `<正文>` 中文标签、`<options>` 选项
  - 无标签纯文本状态尾部（「XX 状态 + emoji 字段」自动拆分）
- 格式校验开关：未按格式输出时自动重试（次数可控）

### 语音
- **TTS**：系统引擎 / ElevenLabs / Azure / OpenAI 兼容，自动朗读开关
- **ASR**：系统识别 + OpenAI 兼容 Whisper 接口（可填 MiMo 等服务），录音转写后作为语音消息发送

### 界面（微信风格）
- 底部三 Tab：**聊天** / **好友** / **我**，支持实时搜索
- 微信绿气泡、灰底分组设置页、底部表单编辑、深色模式（默认浅色/跟随系统）
- 聊天字体大小 14–24sp 全局生效
- 隐私模式：全部图片高斯模糊
- 对话识别：角色台词（「」）绿色着色、内心想法（`*…*`）斜体灰显
- 消息长按：编辑、重新生成；角色消息支持重生成

### 插件实验室（实验功能，默认关闭）
设置路径：插件页 → 实验室 → 插件导入向导

| 能力 | 说明 |
|---|---|
| 角色卡脚本自动导入 | 导入带 `regex_scripts` 的卡时自动转为本地规则，**仅绑定该角色生效** |
| URL / 源码导入 | 下载或粘贴插件 → 自动识别类型 → 大模型转换为规则草稿 → 预览确认后保存 |
| 提示词注入 | `INJECT_PROMPT` 规则：常驻或关键词触发，向系统提示词注入片段 |
| 明确边界 | 依赖浏览器 DOM / 事件 / 酒馆 API 的 JS 扩展会被拒绝转换 |

**回滚**：关闭实验室开关即可（不影响现有功能）；稳定版备份见 `releases/`。

## 技术架构

```
Kotlin + Jetpack Compose · MVVM · Clean Architecture
Room（本地数据库，含平滑迁移）· Hilt 依赖注入
OkHttp + SSE 流式 · kotlinx.serialization · Coil
```

```
com.tavern.app
├── core/
│   ├── parser/      # 角色卡、世界书、状态栏多协议、选项、旁白、IM 解析
│   ├── prompt/      # 提示词构建（世界书/模式/状态/IM/插件注入）
│   ├── plugin/      # 声明式规则引擎 + 插件导入转换器
│   ├── data/        # Room 数据库、Repository、模型 Provider
│   └── model/       # 领域模型
├── feature/         # 聊天、角色、设置、语音、状态栏等界面
└── ui/              # 主题、隐私模糊、渲染组件（TavernText）
```

- **单元测试 130 个**：解析器、提示词、插件引擎、SSE 等纯逻辑全覆盖
- **数据库**：v1 → v7 平滑迁移（角色/会话/消息/配置/状态/插件/ASR）

## 构建与运行

**环境要求**：JDK 17、Android SDK 34、Android Studio Hedgehog+（或本机 Gradle 8.9）

```bash
# Android Studio 直接打开项目即可运行
# 或命令行：
gradle assembleDebug        # 产物：app/build/outputs/apk/debug/app-debug.apk
gradle testDebugUnitTest    # 运行单元测试
```

- `minSdk 26` / `targetSdk 34` / `applicationId com.tavern.app`
- 安装后需自行配置：**我 → 大模型**（ baseUrl / API Key / 模型名），即可开始游玩

## 快速上手

1. **我 → 大模型**：添加模型（如 DeepSeek：`https://api.deepseek.com` + `deepseek-chat`），点「测试」确认连通
2. **好友 → +**：导入 PNG / JSON 角色卡
3. 点击好友 → 详情页选开局 → **开始游玩**
4. 默认进入文字冒险；顶栏可切换视觉小说 / 自由扮演
5. 右下角悬浮球打开手机聊天；**聊天增强**在「我」页开启（双倍 token，沉浸感更好）
6. 视觉小说模式下每轮底部出现行动选项，点击即推进剧情并结算状态

## 版本与分支策略

| 分支 / 标签 | 说明 |
|---|---|
| `main` @ `v0.3-stable` | 稳定版基线，随时可回退 |
| `feature/plugin-import` | 实验功能开发线（插件实验室 + VN 选项增强） |
| `releases/*.apk` | 各版本 APK 备份 |

实验功能统一走「实验室开关，默认关闭」，出问题关开关或装回稳定版即可，无需降级数据。
